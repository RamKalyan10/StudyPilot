# Operating Systems Course Syllabus

## Unit 1: Introduction to Operating Systems and Architecture
- History and Evolution of Operating Systems
- Dual-Mode Operation and System Calls
- OS Structures: Monolithic, Microkernel, Layered Architecture
- Interrupt Handling and Boot Process

## Unit 2: Process Management and CPU Scheduling
- Process Concept, Process State Transition, and PCB
- Context Switching and Inter-Process Communication (IPC)
- Threading Models and Multithreading
- CPU Scheduling Algorithms: FCFS, SJF, Priority Scheduling, Round Robin, Multilevel Feedback Queue

## Unit 3: Process Synchronization and Deadlocks
- Critical Section Problem, Peterson's Solution
- Semaphores, Mutexes, and Monitors
- Classical Synchronization Problems: Producer-Consumer, Readers-Writers, Dining Philosophers
- Deadlock Characterization, Prevention, Avoidance (Banker's Algorithm), Detection and Recovery

## Unit 4: Memory Management and Virtual Memory
- Contiguous Memory Allocation, Fragmentation
- Paging and Segmentation
- Page Replacement Algorithms: FIFO, LRU, Optimal
- Working Set Model and Thrashing

## Unit 5: Storage and File Systems
- Disk Scheduling Algorithms: FCFS, SSTF, SCAN, C-SCAN
- File System Implementation: Inodes, Directory Structures
- Allocation Methods: Contiguous, Linked, Indexed
